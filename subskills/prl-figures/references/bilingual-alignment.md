# 双语对齐与防止语义漂移

采用[v3直接写作策略](assertive-writing.md)：两版先交付正文，必要条件保留在各自判断旁边；详细核查记录另存。需要指出缺项时，说明影响哪项判断的具体资料。证据等级一致允许句法重排，也允许删去两版中各自多余的套话。

两种语言共享同一份[主张账本](claim-ledger.md)，按主张或段落功能对齐，不强求逐句等长。英文可合并中文短句，中文可拆开英文长句，但不能改变一个限定条件约束的对象。

## 工作流程

1. 明确源稿和目标语言；双语同步修改时指定哪份事实记录为准。用户已给出时直接使用。
2. 建立主张ID，标记数值、符号、单位、比较基线、方向、否定、条件、误差定义、图号、引用及论断强度。只有影响科学含义的术语需要专项词表，不给普通词强制一一对应。
3. 以目标语言重写完整论证。先保证信息和逻辑，再处理节奏、搭配和篇幅；不能靠回译式长定语制造“学术感”。
4. 将两版逐项与原始证据核对。回译可以帮助发现问题，但同一模型回译一致不能证明等义。
5. 对需要长期维护的稿件记录受保护片段，运行检查，再完成语义审阅。工具检查通过后仍明确保留语义审阅状态。

## 必查差异

| 维度 | 常见错误 | 验收依据 |
|---|---|---|
| 数量和范围 | 12%变成12个百分点；至少变成至多；范围端点互换 | 数值、单位、分母、方向及端点均与证据一致 |
| 基线 | 相对最短路径改成相对所有方法 | 比较对象和比较条件不变 |
| 否定 | not established译为“不成立”；not significant译为“没有效应” | 区分未证明、证明没有、未检出及未做检验 |
| 限制强度 | 未计算区间写成无法构造任何区间；缺完整协方差写成没有任何参数误差信息 | 核对来源已提供的边际标准差和目标推断所需假设；负面判断也须有依据 |
| 限定 | sampled densities译成“所有密度” | 有限样本、近似条件和未覆盖范围均保留 |
| 因果强度 | consistent with译为“证明了”；association译为“导致” | 观测、解释、假设、机制和因果等级不变 |
| 不确定性 | SD译成标准误；校准不确定度译成置信区间 | 统计对象、误差定义、置信水平和采样方式不变 |
| 图文关系 | 图2(a)变成图2(b)；线与点含义互换 | 同一主张对应同一面板和证据 |
| 术语 | steady state译为稳定态 | 结合模型定义判断，不能只查字典 |
| 量的身份 | 两个系数数值均为1，图轴却换用了另一系数的下标 | 对照来源公式、物理定义及[量台账](claim-ledger.md#physical-quantity-identity-across-sources-figures-and-text)，核查实际轴、图注与两版正文；数值对齐不足以通过 |
| 采样语义 | 73条含重复时刻的记录变成73个不同采样时刻 | 保留记录数、不同坐标数、重复测量及独立样本之间的区别 |
| 运算对象 | “减去”吞掉“去季节化”量名的前缀，导致减数改变 | 用来源定义展开两个操作数，分别核对先后顺序；必要时使用已定义符号 |
| 修饰对象 | 观测年份变成发布日期；两量间协方差变成差值的协方差 | 核对日期、统计量和限定词究竟修饰哪个对象；不能只比较相同数字或术语 |

术语表是上下文参考，不是逐词替换器。中文先围绕共享主张自然起草，再逐项核对；对不确定度的译法不得增加来源没有提供的覆盖概率、独立性或统计定义。单位、项目名称和已定义缩写不需要为“纯中文”而改写。

语义复核时将每个关键句拆成“对象—关系或运算—限定条件”，对照原始事实重新读一遍。受保护片段全部出现，仍可能有分词、代词或修饰范围错误。将此类问题记录为可定位的歧义或含义变化；数值正确时不要虚报为计算错误，也不能因数值正确而省略修订。

## 可执行保护片段

示例：[aligned-example.json](../evals/bilingual/aligned-example.json)。每段包含`id`、`claim_ids`、`en`、`zh`、`protected_facts`。每项数值事实包含`id`、有序`values`、`unit`和两版原文中的`anchors`；例如均值与误差分别按顺序记录。`term_checks`保存具体语境下的术语及禁用译法；`meaning_anchors`可标记比较基线、范围或否定片段以检查是否遗漏。

```bash
.venv/bin/python scripts/check_bilingual.py evals/bilingual/aligned-example.json \
  --ledger assets/templates/claim-ledger.json --output reports/bilingual-example.json
```

工具支持全角数字、百分号/percent、常见英文小整数、显式科学计数法和有限的单位别名。它不会默认推断中文数字、逗号小数、任意单位换算或隐含的量纲关系。精度位数、有效数字和区间开闭性仍须人工或代理核查。需要合法改写保护片段时，先核查事实，再更新片段；不能为了消除报错直接改掉期望值。

若账本包含 `quantity_usages`，同一次命令还需绑定实际产物：使用 `--figure-report 图形ID=/path/figure.json` 和可重复的 `--text 文本ID=/path/caption.md`，ID须与账本一致。图形报告必须匹配同名PDF，文本须为实际交付内容。缺少绑定或物理量身份不符应保留失败；不要删除量台账、忽略失败或仅靠出现相同数字来绕过。输出同时记录账本验证和产物哈希。

简单图号和`[[cite:ID]]`内部引用标记可以比较；实际稿件中的复合图号、引用范围和其他宏仍须完整核查。不得在最终稿中遗留内部引用标记；输出文档时转换为用户要求的引用格式，并再次核对。

## 原创正反例

英文：“The measurements are consistent with collective motion but do not distinguish it from a shared external drive.”

中文：“这些测量结果与集体运动的解释一致，但尚不能将其与共同外部驱动的解释区分开来。”

错误译法：“测量证明了集体运动，而且排除了外部驱动。”它反转了证据强度和排他性。即使所有数值和术语都匹配，仍必须判为失败。

英文：“No statistically significant difference was detected.”

中文：“未检出统计显著差异。”不能改成“两者没有差异”。若原稿没有检验，也不能凭空补这句话。

英文：“A steady state is reached; its stability has not been tested.”

中文：“体系达到稳态，但尚未检验该稳态的稳定性。”不能压缩为“体系达到稳定态”。

双语验收记录应分别给出：机械结果、语义核查者类型、逐项发现、自然度修改、剩余科学问题。没有领域专家参与就标为代理语义审阅，不能写成专家认证或等义证明。
