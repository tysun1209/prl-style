# PRL Fig. 1：流程图与科学示意图

先确定读者需要看懂的物理对象、关系和操作，再决定图的结构。Fig. 1 可以是模型介绍、装置、机制解释、方法流程，也可以直接展示结果；图号不决定图型。

**默认制作流程：内置绘图模型生成 PNG → 看图重建可编辑 PPT → 渲染对照检查。** 先完成视觉设计，再把文字、科学对象与连接关系恢复为独立可编辑元素。具体操作见 [PNG → 可编辑 PPT](schematic-image-pptx.md)。下列文献规则约束科学表达，不要求用 Python 基础图元作为默认出图方式。

## 本指南从哪里来

对已有 100 篇论文的本地 PDF 逐篇检查，定位并查看 96 张 Fig. 1：24 张示意图、24 张混合图、48 张结果图；另 4 篇本地版本无 Fig. 1。分类基于整图总览，对关键例子追加单图和页面检查。来源含出版版本和作者稿，未测量精确字形或颜色频率。

[逐篇来源索引](schematic-sources.json)给出 DOI、PDF 页码、哈希、分类和观察。F001 等编号仅用于本指南索引。沿用原语料 80/20 划分：80 篇开发集中的 37 张示意／混合图用于凝练规则；20 篇留出集中的 11 张作回顾性适用性对照。这里不是独立盲评，也不是 PRL 全刊统计。

## 选构图：按任务，而不是固定套版

| 要解释的内容 | 优先结构 | 开发集依据 |

| 强化学习、控制、反馈 | 环境与控制器分区；动作、观测、奖励分别定向连接 | F001、F009、F018 |
| 数据到模型、测量到优化 | 简短的输入—处理—输出主线；必要时另画约束或更新回路 | F081、F099 |

| 机制、相互作用、局部运动 | 少量代表对象＋方向；必要时配前后状态或相反过程 | F031、F047、F057、F074 |

## 把文献细节转化成绘图决策

1. **让几何承担定义。** 长度标在对应边界附近，角度标在对应方向之间，方向箭头从所指对象出发。F006 将壁间距、粒子位置和取向分开定义；F029 区分内外区域及界面；F094 区分两个参考系。需要坐标时画局部坐标三联线；没有数值坐标就不加常规刻度框。
2. **箭头先有含义，后有样式。** 动作、信息传递、物理运动、力、操作顺序、放大引线不能混为一类。F001/F009 分开反馈通道，F047 分开推进方向与时间顺序，F095 将操作写在阶段之间。每条语义箭头应能回答“谁到谁、传递或改变什么”。只有确为双向关系才用双箭头；尺寸箭头和指引线单独处理。
3. **闭环与时间轴分别排。** 反馈线沿节点外缘绕行，端点接到正确对象；时间序列沿同一主方向展开。F001 的回路与 F095 的阶段序列不是同一种模板。双向反馈通常用两条有各自含义的路径；不以一条无标签双向线代替。
4. **重复对象保留身份。** 跨面板沿用同一物种、粒子、控制器和状态的颜色与符号。F074 的物种颜色贯穿化学场、液滴和相互作用图；F095 的阶段上下对应；F047 的粒子推进方向在不同过程里仍能辨认。颜色变化只有在表示物理状态变化时才改变。
5. **局部放大要有对应。** F031 的放大区连接实际研究对象；F056 的截面补充整体装置读不清的方向；F072 的局部视图解释不同运动情况。引线连接局部边界或关注区域，避免看起来像作用力；放大与主图可用不同尺度，在图注说明，不编造比例尺。
6. **区分结构色与数值色。** 类别颜色标识实体，连续色标表达场值。F006 同时用了表面速度色标与黄色粒子几何；F047 的热图和粒子动作使用不同编码。调用 [PRL 配色库](prl-color-palettes.md)，为每个对象记录映射；存在物理量才使用渐变和色标，不给流程步骤任意套彩虹渐变。
7. **先分配解释空间，再排数据。** F001 是宽示意加三个结果面板；F068 是几何与流场加曲线；F090 是整体加两个截面。按实际内容分配宽度，示意图和数据图不必等大。规则网格对齐实际图形区域，专门给色标留位置；用空白分组而不是大段文字隔开面板。
8. **必要标签贴近对象。** 粒子、方向、边界条件、操作、关键变量属于阅读标签，可以放在图中。长解释、推导、参数表和结论进图注。F094 的公式文字较多，F099 有较大的文字节点，说明真实论文也有例外；本 skill 默认简洁标签的选择来自用户设置，而不是声称 PRL 禁止文字。
9. **立体只用于解释深度。** F052 的层状结构、F056 的装置与 F090 的剖切需要深度关系；F065 的单列粒子和 F092 的器件在平面中已足够清楚。优先平面图，确需三维再使用一致投影和遮挡；材质、阴影和高光不承担未定义的定量含义。
10. **机制与证据在图注中交代。** F057 的机制面板与稳定性结果并置，F093 的曲线表达工作原理。自创定性轮廓、粒子布局、操作示意必须与实际模拟、照片、测量区分；用户未给结果时，交付示意图，不补造“效果曲线”。

## 本项目的默认绘制参数

以下为可调的本地实现选择，不是从 100 篇测得的众数，也不是期刊硬性要求。

- 英文和数字用 Times New Roman，中文用宋体；沿用 [字体处理](typography.md)，缺字体时明确指出，不安装字体、不静默替换。
- 简单单栏构图可从 85 mm 宽开始；多个阶段、长标签、反馈回路或混合图可从 178 mm 宽开始。按最终阅读尺寸排版，拥挤时先删掉无关结构或扩大画布，不缩小文字救布局。
- 普通标签从 10 pt、面板标号从 10.5 pt 开始；结构线约 0.8–1.1 pt，语义箭头约 1.1–1.3 pt。检查实际字高与字形，特别是上下标。
- 流程节点用白底或低饱和填充，语义主体用选定配色；箭头尖端停在节点边界。标签留白、路径绕行距离随最终尺寸调整。
- 示意区默认没有坐标轴边框、数值刻度、图例框或标题横幅。必要量标和比例尺照常保留；数据面板遵守普通绘图的刻度、字体和图例规则。
- 默认交付**模型 PNG 和可编辑 PPTX**，图注另存。以最终尺寸下 600 dpi 为目标，保留并报告模型原生像素数；原生 PPT 对象可另渲染为 600 dpi PNG。PDF、SVG、EPS 按需输出。

## 默认流程与可选代码绘制

默认调用当前宿主的图像生成工具，再用 `scripts/schematic_to_pptx.py` 把 agent 看图后编写的 scene 导出为 PPTX。查看[重建指南与完整示例](schematic-image-pptx.md)。导出器负责生成真正的 PowerPoint 对象，不自动识别 PNG 内容。

用户明确要求代码绘制时，使用下面的原有资源：

`scripts/prl_schematic.py` 提供以毫米定位的 `panel`、`Diagram.node`、`Diagram.edge` 和 `Diagram.arrow`，复用现有字体、配色和导出器。画布几何本身可用 Matplotlib 的 Circle、Polygon、Path 等原语自由构造；不要把所有物理对象都画成流程框。

```bash
python scripts/render_schematics.py --all --output figures/fig1-examples
python scripts/render_schematics.py --example feedback --output figures/control
python scripts/render_schematics.py --example protocol --formats png pdf --output figures/protocol
```

六个示例分别是活性粒子几何、实验装置、反馈控制、数据处理流程、操作协议、模型与数据混合图，均为原创演示。适配用户科学内容时读取 [示例源码](../scripts/render_schematics.py) 中相应函数，用真实对象和关系替换，而不是只换图中文字。混合图的样例曲线是明确构造的演示数据，不是论文结果。

## 交付前检查

先对照用户内容核查实体、边界、箭头方向、操作顺序、符号与量纲；再看最终尺寸图片。逐一检查箭头是否穿过无关节点、标签是否压住结构、圆形是否拉伸、放大框是否对应、相同对象颜色是否一致、上下行是否对齐。混合图还需检查数据面板和色标。

对默认流程，检查实际打开／渲染后的 PPT，确认文字、箭头和主要科学对象可独立编辑，且构图与模型 PNG 一致。对可选 Python 流程，原有辅助检查可发现节点标签溢出、重复标识、无效端点及直线路段穿越节点。两者都需要目视核查科学关系与排版。审查明细另存，不塞进图面或正文。
